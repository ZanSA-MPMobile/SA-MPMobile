// Frequently asked

Quick answers.

Informasi singkat sebelum kamu mengunduh dan menjalankan Zan SA-MP Mobile.

Apakah Zan SA-MP Mobile gratis?

Ya. Build publik dapat diunduh langsung melalui tombol Download APK di website ini.

Di perangkat apa client ini berjalan?

Zan SA-MP Mobile dibuat untuk perangkat Android. Pastikan perangkat memiliki ruang penyimpanan yang cukup sebelum memasang APK.

Bagaimana cara mendapatkan versi terbaru?

Website membaca versi dan tautan APK dari update.json. Tombol download akan otomatis mengarah ke build resmi terbaru.

Bagaimana cara mendapatkan bantuan atau melaporkan bug?

Bergabunglah dengan komunitas Discord kami — laporan bug dan permintaan bantuan ditangani di sana.
